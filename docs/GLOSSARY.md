# Glossary: German ↔ English

| German / abbreviation | English | One-line meaning |
|---|---|---|
| **Krankenbeförderung** | Patient transport | Umbrella term for all medically prescribed trips |
| Krankenfahrt | Patient ride | Trip by taxi or rental car, no medical care on board |
| **Krankentransport** | Patient transport (medical) | Trip by KTW with trained staff |
| Rettungsfahrt | Rescue trip | Emergency (RTW/NAW), out of scope |
| **Muster 4** | Form 4 | The double-sided paper prescription for patient transport |
| **Verordnung / eVerordnung (eVO)** | Prescription / e-prescription | The doctor's order. "eVO" = electronic version |
| **Fachdienst** | Specialist (back-end) service | Central server holding e-prescriptions, like the eRezept server |
| **TI, Telematikinfrastruktur** | Telematics Infrastructure | Germany's closed, secure health data network, run by gematik |
| TI 2.0 | Next-gen TI | Internet-based, zero-trust redesign of the TI (ZETA, PoPP, GesundheitsID…) |
| **gematik** | (company name) | National agency for digital health. Majority owned by the Federal Ministry of Health |
| **Krankenkasse (KK) / GKV** | Statutory health insurer / statutory health insurance | Pays for the trips. Examples: TK, AOK, Barmer, DAK |
| GKV-SV (GKV-Spitzenverband) | National association of statutory health insurers | Sets billing rules |
| **KBV / KV** | (National / regional) Association of Statutory Health Insurance Physicians | Doctors' self-government. Publishes forms and fill-in guides |
| G-BA | Federal Joint Committee | Writes the patient-transport guideline (KT-RL) |
| KT-RL | Patient Transport Guideline | Legal rules for who gets what transport |
| Selbstverwaltung | Self-governing bodies | Doctors' and insurers' associations that set rules together |
| Bundesmantelvertrag (BMV) | Federal Framework Agreement | Contract between KBV and GKV-SV. The forms are its annex |
| **SGB V § 60** | Social Code Book V, § 60 | Law: insurer pays travel costs if medically necessary |
| **Genehmigungsfrei / genehmigungspflichtig** | Approval-free / approval-required | Whether the insurer must approve **before** the trip |
| **Transportunternehmen / Transporteur / Fahrdienst(leister) (FDL)** | Transport company / provider | Taxi, rental car or KTW operator |
| **Taxi / Mietwagen** | Taxi / rental car with driver | Basic ride. Mietwagen may be wheelchair-adapted |
| **KTW, Krankentransportwagen** | Patient transport ambulance | Vehicle with medical staff and equipment (stretcher, carry chair) |
| RTW, Rettungswagen | Emergency ambulance | Emergency, 112 |
| NAW / NEF | Emergency-doctor ambulance / vehicle | Emergency with physician |
| **Rollstuhl** | Wheelchair | Patient travels in their own wheelchair |
| **Tragestuhl** | Carry chair | Patient sits and is carried by 2 people (e.g. stairs) |
| **liegend** | Lying down | Needs a stretcher |
| **Hinfahrt / Rückfahrt** | Outbound / return trip | Prescribed and confirmed separately |
| **Zuzahlung** | Co-payment | Legal patient contribution: 10% of cost, min €5, max €10 per trip |
| **Zuzahlungsbefreiung** | Co-payment exemption | Patient has reached their annual limit (§ 62 SGB V) |
| Unfall / Arbeitsunfall / Berufskrankheit | Accident / work accident / occupational disease | Work-related cases are paid by the accident insurance (Berufsgenossenschaft) |
| Versorgungsleiden (BVG) | State-compensated condition (War Victims Act) | Damage from war, crime or vaccination, recognised by the state |
| Merkzeichen aG / Bl / H / G | Disability card markers | aG = exceptional walking disability, Bl = blind, H = helpless, G = significant mobility impairment |
| Pflegegrad 1–5 | Care level 1–5 | Long-term-care dependency level |
| Dialyse / Chemo- / Strahlentherapie | Dialysis / chemo- / radiotherapy | Typical high-frequency "series" treatments |
| vor-/nachstationär | Pre- / post-inpatient | Hospital-related outpatient visits around a stay |
| Verlegung | Transfer | Moving a patient between hospitals |
| Gemeinschaftsfahrt | Shared ride | Several patients in one vehicle |
| Wartezeit | Waiting time | Driver waits at the facility for the return trip |
| Serienfahrt / Dauergenehmigung | Series trip / permanent approval | Recurring trips under one approval |
| **Leistungsbestätigung / eLeistungsbestätigung** | Service confirmation / e-confirmation | Proof the trip happened (today: signature on the back of Muster 4) |
| **Abrechnung / DTA** | Billing / electronic data exchange | Electronic billing from provider to insurer (§ 302 SGB V) |
| TP5 (Technische Anlage 5) | Technical Annex 5 | Existing GKV electronic procedure, suggested for confirmations |
| **IK, Institutionskennzeichen** | Institution ID | 9-digit ID of insurers and providers, used in billing |
| Belegnummer / Rechnungsnummer | Receipt number / invoice number | Billing references |
| Positionsnummer | Billing position code | Tariff item code |
| Versichertennummer (KVNR) | Health insurance number | Lifelong patient ID: 1 letter + 9 digits |
| **eGK** | Electronic health card | Every insured person's chip card, NFC-capable |
| SMC-B | Institution smart card | Card that lets an institution log into the TI |
| PVS / KIS / AVS | Practice / hospital / pharmacy software | "Primary systems" that talk to the TI |
| **eRezept** | E-prescription for medicine | Live since 2024. QR token = task ID + access code |
| ePA | Electronic patient record | |
| **PoPP** | Proof of Patient Presence | TI 2.0 service: tap the eGK (NFC) → signed token proving the patient was present |
| **WANDA** | Further applications for data exchange in the TI | Framework for non-core applications using TI infrastructure |
| ZETA | Zero Trust Access | TI 2.0 access layer |
| GesundheitsID | Health ID | Digital identity for insured persons (app login) |
| TI-Messenger | TI messenger | Secure messaging in healthcare (Matrix-based) |
| Behandlungsstätte / Einrichtung | Treatment facility | Destination |
| Wohnanschrift | Home address | Usual pickup point |
| Vertretung durch Dritte | Representation by a third person | Proxy, e.g. a relative signing |
| Soll-Prozess / Ist-Prozess | Target process / current process | |
